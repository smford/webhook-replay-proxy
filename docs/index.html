webhook-replay-proxy

Production-grade webhook capture, replay, and inspection proxy for edge and cloud environments.

Current Release: v0.1.0 (0.1.0)

Homebrew Installation

brew install smford/homebrew-tap/webhook-replay-proxy

Docker Container

docker run -d -p 8080:8080 ghcr.io/smford/webhook-replay-proxy:v0.1.0

Or download precompiled standalone binaries from GitHub Releases.

Quick Start

# Start the proxy daemon
webhook-replay-proxy -port 8080

# Send a test webhook
curl -X POST http://localhost:8080/api/v1/webhooks \
  -H "Content-Type: application/json" \
  -d '{"event": "payment.succeeded", "amount": 4200}'

# Verify health status
curl http://localhost:8080/healthz
